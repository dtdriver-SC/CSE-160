
## Controls

* Mouse drag: orbit around the scene
* Mouse wheel: zoom in and out
* Right mouse drag: pan
* Start Game button: starts the scavenger hunt
* Stop Game button: stops the scavenger hunt

## Game Instructions

The game randomly chooses one music item for the player to find. The player has 10 seconds to click the correct item.

Items included in the game:

* Keyboard
* Mic Stand
* Mic
* Vinyl
* Headphones
* Boombox
* Record Player

If the player clicks the correct item, they win the round and a new random item is selected. If the timer runs out, the game also resets to a new random item.

The game portion is a little wonky, but I tried to make it work as a simple interactive scavenger hunt using mouse clicking and invisible hit boxes.
